02 · L’installation

Un projet dédié.
Un départ propre.

Le ZIP contient les définitions des agents et les guides. Les accès à Codex, Google et Ranxplorer se configurent avec vos propres comptes.

  1. Téléchargez le ZIP et collez le prompt

    Depuis GitHub, récupérez le ZIP du pack. Joignez-le à un chat Work local ayant accès aux fichiers de votre ordinateur, puis collez le prompt ci-contre. L’assistant examine le pack et prépare un nouveau dossier dédié avec les 32 agents.

  2. Ouvrez le dossier comme nouveau projet

    Si l’assistant ne peut pas ajouter le projet dans l’application, choisissez Ajouter un projet → le dossier préparé → nouveau chat. Le dossier contenant .codex/agents/ doit être la racine du projet. Remplissez ensuite seo/CONTEXTE.md.

  3. Activez vos sources de données

    Suivez le guide Google et le lanceur du pack pour la lecture Search Console. Pour Ranxplorer, configurez votre accès API personnel, puis le serveur MCP du projet. Fixez le budget de crédits avant les collectes.

  4. Rouvrez le projet et vérifiez

    Ouvrez un nouveau chat pour charger les rôles et les connexions. Faites vérifier les 32 noms d’agents, puis gsc_connection_status et gsc_list_sites, avant la première mission.

À COLLER DANS WORK LOCAL · AVEC LE ZIP

Installe le ZIP joint dans un nouveau projet Work local dédié à mon équipe SEO Codex. Examine le contenu avant toute exécution, puis suis INSTALLER.md pour créer un nouveau dossier avec les 32 agents, sans modifier mes autres projets ni mes réglages globaux. Vérifie les fichiers installés et ouvre un nouveau chat dans ce projet si les outils de l’application le permettent ; sinon indique précisément le clic restant pour ajouter le dossier comme projet. Prépare les connexions et guide-moi pour les autorisations personnelles Google et Ranxplorer, sans demander de clé, mot de passe ou jeton dans le chat. Termine avec le directeur SEO prêt à recueillir le contexte de mon site ; n’annonce aucune connexion ni aucun lancement d’agent qui n’a pas été vérifié.

Le prompt guide la préparation des fichiers. L’ajout du dossier à la liste des projets peut demander un clic dans l’application. Les autorisations Google et Ranxplorer restent personnelles.

Les agents personnalisés se chargent depuis le dossier du projet. Documentation officielle OpenAI ↗

Pour autoriser Google : Python 3.11+ est nécessaire. Dans votre projet Google Cloud, activez l’API Search Console et créez un client OAuth « Application de bureau » ; en mode test, ajoutez votre compte aux utilisateurs de test. Gardez le fichier OAuth hors du pack. Sous Windows, lancez CONNECTER_SEARCH_CONSOLE.cmd, choisissez ce fichier, autorisez la lecture dans Google et sélectionnez la propriété du site. Le guide seo/OUTILS_GSC.md détaille ces étapes.

04 · Les workflows

Du besoin au livrable.
Sans repartir de zéro.

Quatre enchaînements pour coordonner les agents dans Codex avec les sources disponibles. Remplacez les champs entre crochets.

WORKFLOW A

Le point du lundi

Comprendre ce qui évolue et choisir les trois prochaines actions.

seo-reporting → seo-quick-wins → seo-priorisation → seo-directeur
Voir le prompt à coller dans Codex

Workflow du lundi pour [site]. Vérifie la propriété Search Console connectée. Utilise seo-reporting avec gsc_compare_periods, puis seo-quick-wins avec gsc_search_analytics. Si la connexion manque, utilise les exports comparables fournis et signale cette limite. seo-priorisation met à jour le backlog local ; seo-directeur propose les trois actions de la semaine. Attends ma validation avant de lancer ces actions.

WORKFLOW B

Préparer une page

Passer d’une requête à un brouillon documenté, relu et relié au site.

seo-intention → seo-brief → seo-redacteur → seo-relecteur-eeat → seo-ancres
Voir le prompt à coller dans Codex

Je veux une page sur la requête [requête]. Enchaîne seo-intention, seo-brief, puis seo-redacteur après validation du brief, seo-relecteur-eeat, seo-title-meta et seo-donnees-structurees. Termine avec seo-ancres. Utilise Ranxplorer pour les données qu’il expose et les sources fournies pour le reste. Montre le résultat final avant toute publication.

WORKFLOW C

Une page qui décroche

Confirmer la baisse et préparer les corrections avant de modifier la page.

seo-chute-trafic → seo-cannibalisation → seo-mise-a-jour → seo-title-meta
Voir le prompt à coller dans Codex

La page [URL] perd des clics. Confirme cette baisse dans Search Console avec gsc_compare_periods et un filtre sur la page, ou avec les exports comparables si la connexion manque. Lance seo-chute-trafic pour le diagnostic, puis seo-cannibalisation si les données permettent cette vérification. seo-mise-a-jour propose les modifications exactes et seo-title-meta un nouveau title. Rends un plan avant/après, sans modifier le site.

WORKFLOW D

Étudier les citations IA

Analyser des réponses observées et préparer des pistes documentées.

seo-crawlers-ia → seo-geo-visibilite → seo-opportunites-liens → seo-outreach
Voir le prompt à coller dans Codex

Pour la question [question client], utilise seo-crawlers-ia pour les contrôles techniques, puis seo-geo-visibilite à partir des réponses datées fournies. Si ces observations manquent, prépare leur collecte. seo-opportunites-liens exploite les exports détaillés disponibles et seo-outreach prépare les brouillons. Je valide chaque envoi.

À activer · validation réelle à effectuer

Votre site : Search Console

Le connecteur local du pack comprend six outils en lecture seule : état de connexion, propriétés, performances, comparaison de périodes, inspection d’URL et sitemaps. Il n’a pas encore été validé sur un compte Google réel lors de la préparation de cette version.

Après autorisation : clics, impressions, CTR et position moyenne sur la propriété sélectionnée. L’inspection restitue l’état connu de Google ; elle ne lance pas de demande d’indexation.

À configurer · API & crédits personnels

Le marché : Ranxplorer

Le MCP officiel donne accès aux outils disponibles de mots-clés, de concurrence et de visibilité. Les résultats sont des données de marché et des estimations selon les outils, dates et périmètres interrogés.

L’accès API personnel et les crédits doivent être vérifiés séparément d’un accès à l’interface web. Les conditions et tarifs sont à consulter chez Ranxplorer.

Avant de vous lancer

Faut-il connecter Ranxplorer pour utiliser les agents ?

Vous pouvez commencer avec vos propres exports et documents. La collecte directe par le MCP Ranxplorer exige votre accès API et des crédits. Les coûts de Codex et des services externes ne sont pas inclus dans les fichiers du pack.

Les agents peuvent-ils publier ou envoyer des messages ?

Le pack prépare des analyses et des brouillons locaux. Les publications, suppressions, prises de contact et dépenses demandent l’autorisation humaine prévue dans le mandat. Relisez les livrables et leurs sources.

Est-ce une ressource officielle OpenAI ?

Il s’agit d’une adaptation technique indépendante par WebSolution24. Cette adaptation n’est pas une publication officielle d’OpenAI, de Google ou de Ranxplorer.
